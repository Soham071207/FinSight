# FinSight ML Pipeline — Reproducibility Package

> Full quantitative stock prediction pipeline for the SCI Journal paper:
> **"FinSight: A Multi-Scale Deep Ensemble Framework for Stock Market Prediction
> with Self-Supervised Pre-Training, Graph Neural Networks, and Bayesian Uncertainty Quantification"**

---

## Requirements

Python 3.9+ (tested on 3.13.1). No GPU required — all components run on CPU.

```bash
pip install -r requirements.txt
```

> **Note on TensorFlow:** TS-TCC pre-training uses TensorFlow for the GRU cross-predictor.
> On Windows, CPU execution works natively. For GPU, use TensorFlow-DirectML or WSL2 + CUDA.

## Reproducing All Paper Tables

Run scripts in this order to reproduce all tables and figures:

### Step 1 — Download Data
```bash
python download_static_data.py
```
Downloads 5 years of OHLCV data for all 50 NIFTY-50 tickers from Yahoo Finance.
*Time: ~5 minutes (network-dependent).*

### Step 2 — TS-TCC Self-Supervised Pre-Training
```bash
python pretrain.py
```
Pre-trains the TCN-MHA encoder on all 50 tickers using temporal and contextual contrasting.
Saves: `ts_tcc_encoder.weights.h5` (386 KB).
*Time: ~20 minutes on CPU.*

### Step 3 — Full Walk-Forward Evaluation (Table V)
```bash
python run_offline_evaluation.py
```
Runs strict walk-forward evaluation (70/10/20 split) on all 49 evaluated tickers.
Saves: `true_metrics.json`, `per_ticker_predictions.json`.
*Time: ~45-90 minutes on CPU.*

### Step 4 — Statistical Significance Tests (Table VI)
```bash
python run_significance_tests.py
```
Computes McNemar's test, Wilcoxon signed-rank test, and Diebold-Mariano test
against all baselines. Saves: `significance_results.json`.
*Time: ~2 minutes.*

### Step 5 — Ablation Study (Table VII)
```bash
python run_fast_ablation.py
```
Runs component ablation on 5-ticker holdout set (RELIANCE, TCS, HDFCBANK, INFY, ICICIBANK).
Each run disables exactly one component with all others active.
Saves: `ablation_results.json`.
*Time: ~10 minutes on CPU.*

### Step 6 — Market Regime Analysis (Table X)
```bash
python run_regime_analysis.py
```
Decomposes out-of-sample AUC across four market regimes (Bear/Bull × Trending/Ranging).
Saves: `regime_results.json`.
*Time: ~5 minutes.*

### Step 7 — Walk-Forward Backtest (Table XI)
```bash
python run_backtest_final.py
```
Simulates long-only walk-forward strategy with 10 bps transaction costs on all 49 tickers.
Saves: `backtest_results.json`.
*Time: ~10 minutes.*

### Step 8 — Regenerate Paper
```bash
cd ..  # project root
python generate_finsight_paper.py
```
Self-contained paper generator — reads all JSON files and produces `FinSight_SCI_Journal_Paper.docx`.
*Time: ~5 seconds.*

## Running the API Server

```bash
python main.py
```

Launches Flask API at `http://127.0.0.1:5000`.

| Endpoint | Method | Returns |
|----------|--------|---------|
| `/health` | GET | Server status |
| `/predict/<TICKER.NS>` | GET | `{signal, confidence, regime, uncertainty}` |
| `/regime/<TICKER.NS>` | GET | Current market regime |
| `/uncertainty/<TICKER.NS>` | GET | MC uncertainty estimate |
| `/backtest/<TICKER.NS>` | GET | Walk-forward Sharpe ratio |

## Key Source Files

| File | Purpose |
|------|---------|
| `config.py` | All hyperparameters and paths |
| `data_pipeline.py` | Data download + feature matrix construction |
| `feature_engine.py` | 32 technical features (indicators, GARCH, sentiment) |

| `garch_model.py` | GARCH(1,1) via arch package |

| `backtest_engine.py` | Walk-forward backtest with transaction costs |

## Reproducibility Notes

- **Seed:** All runs use `np.random.seed(42)` and `random.seed(42)`.
- **No leakage:** Standardization, GARCH, and correlation matrices are fit on training data only.
- **Temporal split:** 70% train, 10% validation, 20% test (strictly chronological, no shuffling).
- **Data source:** Yahoo Finance via `yfinance` (internet access required for data download).
