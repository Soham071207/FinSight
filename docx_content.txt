3. FIELD OF THE INVENTION
The present invention relates generally to the field of financial technology (FinTech), and more particularly to a computer-implemented artificial intelligence (AI) and machine learning (ML) based system and method for unified personal finance management. The invention specifically pertains to (a) a multi-stage stacking-ensemble architecture for predictive stock market signal generation that combines sequence models, gradient-boosted tree classifiers, econometric volatility models, and natural language processing (NLP) based sentiment analysis with a calibrated meta-learner; (b) an on-device natural-language/regex based transaction extraction system for private expense tracking; (c) a multi-criteria risk-adjusted mutual fund ranking and simulation engine; and (d) a deterministic, explainable credit-score estimation module.
4. BACKGROUND OF THE INVENTION
In the current digital era, retail investors and everyday individuals rely on a fragmented ecosystem of standalone applications to manage personal finances — one application for stock market tracking, another for credit-score monitoring, a separate platform for mutual fund investment, and yet another for expense tracking. This fragmentation results in “app fatigue,” disjointed financial insights, duplicated data entry, and an inability to make holistic, cross-domain financial decisions.
Existing stock-prediction tools available to retail users typically rely on a single model family (e.g., a lone LSTM network or a single gradient-boosted tree model), evaluated non-deterministically (e.g., against live, unseeded data pulls), which makes reported performance difficult to reproduce and prone to overstatement. Such systems frequently fail to jointly account for (i) long-and-short-range temporal dependencies in price sequences, (ii) regime-dependent behaviour of technical indicators, (iii) volatility clustering, and (iv) concurrent market sentiment derived from unstructured financial news — leading to brittle predictions and poorly calibrated confidence estimates.
Existing expense-tracking solutions commonly transmit sensitive financial SMS data to cloud servers for AI-based parsing, creating privacy and data-security exposure. Existing mutual-fund discovery tools typically rank funds by trailing absolute returns alone, without jointly accounting for risk-adjusted performance, downside risk, and consistency. Existing credit-scoring tools available to retail users are largely opaque “black-box” estimates that provide a number without an explainable, actionable basis for improvement.
There is, therefore, a need for a unified system that (a) improves the technical accuracy, calibration, and reproducibility of AI-based stock-trend prediction through a purpose-built multi-model stacking architecture; (b) preserves user privacy by performing sensitive parsing entirely on-device; (c) evaluates mutual funds on a defensible, risk-adjusted multi-criteria basis; and (d) provides transparent, explainable credit scoring — all within a single integrated ecosystem.
5. OBJECTS OF THE INVENTION
To provide a unified, cross-platform personal finance application that integrates AI-based stock prediction, private expense tracking, mutual fund analysis, and credit scoring within a single ecosystem and a common microservices backend.
To provide a stock-trend prediction module that combines a Temporal Convolutional Network (TCN) and an attention-augmented Long Short-Term Memory (LSTM) network for sequence modelling, a global LightGBM classifier that uses market regime as a categorical feature, and a GARCH-family volatility model, whose outputs are combined by a calibrated stacking meta-learner.
To improve probability calibration and decision-threshold selection in the stacked ensemble through isotonic regression calibration and a Youden's-J-statistic-optimized classification threshold, rather than a fixed default threshold.
To incorporate macroeconomic and cross-sectional context — including implied-volatility indices, currency exchange rates, commodity benchmarks, and sector-relative return features — into the predictive feature set so that model signals reflect broader market conditions and not price history alone.
To provide a dual-pipeline natural-language-processing sentiment layer (a transformer-based financial-domain model and a lexicon-based model) whose combined output is fused with the technical/statistical model outputs.
To provide an intelligent, privacy-preserving expense tracker that parses financial SMS notifications entirely on-device through a multi-stage regular-expression pipeline, without transmitting raw message content to any external server.
To provide a mutual-fund recommendation engine that ranks funds using a weighted, risk-adjusted composite score derived from Extended Internal Rate of Return (XIRR), historical risk/volatility, the Sortino ratio, and maximum drawdown, in place of simple trailing-return ranking.
To provide a deterministic, explainable (“white-box”) credit-score estimation module capable of operating fully offline, which identifies the weakest contributing factors and generates specific, actionable improvement recommendations.
6. SUMMARY OF THE INVENTION
The present invention discloses a computer-implemented system and method for a unified AI-powered personal finance ecosystem, termed “FinSight.” The system comprises a cross-platform mobile application frontend communicating with a containerized microservices backend, and encompasses four functionally-integrated modules, summarized below and described in detail in Section 8.
Module 1 — Stacking-Ensemble AI Stock Prediction Engine
A multi-stage ensemble that generates BUY / SELL / HOLD signals with an associated calibrated confidence score. Base learners comprise a Temporal Convolutional Network and an attention-augmented LSTM for sequence/pattern modelling, a single global LightGBM classifier that treats detected market regime as a categorical input feature (in place of training separate per-regime models), and a GARCH-family model for volatility estimation. A dual sentiment pipeline (a financial-domain transformer model and a lexicon-based sentiment model) scores aggregated financial news. Base-learner outputs, engineered technical indicators, and macro/sector features (implied-volatility index, currency exchange rate, commodity benchmark, sector-relative return) are combined by a stacking meta-learner, whose output probabilities are isotonic-calibrated and thresholded using a Youden's-J-statistic-optimized cut-off rather than a fixed 0.5 threshold.
Module 2 — Privacy-Preserving On-Device Expense Tracker
A five-stage regular-expression parsing pipeline that intercepts bank/financial SMS notifications on-device, extracts transaction amount, merchant, and category, and distinguishes genuine debit/credit transactions from promotional or informational messages — with no transmission of message content off-device.
Module 3 — Multi-Criteria Mutual Fund Recommender
A recommendation engine that synchronizes fund Net Asset Value (NAV) data on a scheduled basis and ranks domestic mutual funds and international ETFs using a weighted composite score of the form (illustrative weighting: 40% XIRR − 30% Risk + 20% Sortino Ratio − 10% Maximum Drawdown), together with a step-up Systematic Investment Plan (SIP) simulator based on geometric-progression modelling of contribution growth.
Module 4 — Deterministic Explainable Credit Score Calculator
A rule-based, deterministic scoring engine that evaluates standard credit factors on-device, produces an estimated score together with a breakdown of contributing factors, and generates ranked, actionable improvement recommendations tied to the weakest-performing factors.

8. DETAILED DESCRIPTION OF THE INVENTION
The following description enables a person skilled in the art to make and use the invention. Specific technology names (e.g., Flutter, Riverpod, Hive, Flask, Docker) are given as illustrative, non-limiting exemplary implementations; the invention is not restricted to these specific technologies and may be implemented using functionally equivalent alternatives.
8.1 System Architecture
The system is built on a client-server architecture. The frontend is implemented using a cross-platform application framework with reactive state management and local NoSQL on-device storage for data persistence and privacy of sensitive records. The backend comprises independently deployable microservices, packaged within containerized runtime environments and fronted by a caching layer for reduced latency. Communication between frontend and backend occurs over secure authenticated API calls, with sensitive parsing (Module 2) and scoring (Module 4) executed on-device rather than server-side.
8.2 Module 1: Stacking-Ensemble Stock Prediction Engine
This module implements a multi-stage, multi-model hybrid architecture for generating trend-prediction signals, comprising the following functional stages:
Sequence-modelling base learners: a Temporal Convolutional Network (TCN) and an attention-augmented LSTM network, each trained on historical price/technical-indicator sequences to capture short- and longer-range temporal dependencies and to weight the most informative time-steps via the attention mechanism.
Regime-aware tree-based base learner: a single global LightGBM gradient-boosted classifier trained across all detected market regimes, with the regime label supplied as a categorical input feature — in contrast to training multiple separate regime-specific models, which improves data efficiency and avoids per-regime data starvation.
Volatility modelling: a Generalized Autoregressive Conditional Heteroskedasticity (GARCH) model estimates conditional volatility, supplying a volatility-regime feature to the downstream meta-learner.
Sentiment analysis: a dual-pipeline NLP subsystem scores aggregated financial news using (i) a transformer-based financial-domain sentiment model and (ii) a lexicon/rule-based sentiment scorer, whose outputs are fused into a composite sentiment feature.
Macro/sector feature integration: engineered features derived from an implied-volatility index, a relevant currency exchange rate, a commodity benchmark, and sector-relative return metrics are appended to the model feature set to contextualize instrument-level predictions within broader market conditions.
Meta-learning and calibration: a stacking meta-learner (e.g., a regularized regression-based combiner) ingests the outputs of the sequence models, the regime-aware classifier, the volatility model, the sentiment features, and the macro/sector features to produce a combined prediction probability. This probability is passed through an isotonic regression calibration step to correct for miscalibration typical of ensembled classifiers, and a final BUY/SELL/HOLD decision is issued using a classification threshold selected by maximizing the Youden's J statistic on validation data, rather than an arbitrary fixed threshold.
The resulting architecture is designed to be evaluated reproducibly — that is, using a deterministic, seeded data-retrieval and evaluation pipeline — such that the reported predictive performance and confidence intervals are independently reproducible, which itself constitutes a technical improvement over ad hoc non-deterministic evaluation practices common in comparable systems.
8.3 Module 2: Privacy-Preserving On-Device Expense Tracker
Rather than transmitting raw SMS content to a server for AI-based classification, this module intercepts incoming financial SMS notifications and processes them through a five-stage on-device regular-expression pipeline: (1) message pre-filtering to identify financial notifications; (2) transaction-amount extraction; (3) merchant/counterparty name extraction; (4) transaction-category classification; and (5) debit/credit and promotional-message disambiguation to exclude non-transactional messages (e.g., credit-limit alerts, marketing messages) from expense records. All parsing occurs entirely on the user's device, and no message content leaves the device, ensuring complete data privacy while retaining automated categorization comparable to cloud-based alternatives.
8.4 Module 3: Multi-Criteria Mutual Fund Recommender
This module automates periodic synchronization of fund Net Asset Value (NAV) data (e.g., via a scheduled data pipeline) and computes, for each fund, a composite risk-adjusted score as a weighted function of: Extended Internal Rate of Return (XIRR); historical risk/volatility; the Sortino ratio (downside-risk-adjusted return); and maximum drawdown. An illustrative, non-limiting weighting is 40% XIRR, −30% Risk, +20% Sortino Ratio, −10% Maximum Drawdown; the relative weights are configurable. This composite ranking is used in place of ranking by trailing absolute returns alone, prioritizing consistency and downside protection. The module additionally includes an investment simulator that models step-up Systematic Investment Plans (SIPs) using geometric-progression-based contribution growth to project future corpus value under user-specified step-up rates.
8.5 Module 4: Deterministic Explainable Credit Score Calculator
This module implements a deterministic, rule-based (“white-box”) model that evaluates standard credit-health factors (e.g., repayment history, credit utilization, credit age, account mix, and recent inquiries) entirely on-device, without requiring network connectivity or exposing underlying financial data externally. In addition to producing an estimated score, the module identifies the lowest-performing contributing factor(s) and generates ranked, specific, actionable recommendations for improving each — providing an explainable alternative to opaque proprietary scoring models.
8.6 Integration and Data Flow
The four modules share common user, account, and preference data through the backend microservices layer, enabling cross-module insights (for example, credit-score trends informing mutual-fund risk suitability, or expense patterns informing SIP step-up recommendations), while sensitive raw data (SMS content, on-device-computed credit factors) is never required to leave the user's device to enable such integration, since only derived, non-sensitive summary indicators are synchronized to the backend.
9. CLAIMS
We claim:
An artificial-intelligence-powered unified personal finance management system comprising: an AI-based stock-trend prediction module utilizing a stacking-ensemble architecture; an on-device expense-tracking module; a mutual-fund evaluation and recommendation module based on a multi-criteria risk-adjusted formula; and a deterministic, explainable credit-score calculation module; wherein said modules are integrated within a single cross-platform application communicating with a common microservices backend.
The system as claimed in claim 1, wherein the stock-trend prediction module comprises: a Temporal Convolutional Network and an attention-augmented Long Short-Term Memory network as sequence-modelling base learners; a single global LightGBM classifier trained across multiple market regimes using detected market regime as a categorical input feature; a Generalized Autoregressive Conditional Heteroskedasticity (GARCH) volatility model; and a stacking meta-learner configured to combine the outputs of said base learners with sentiment features and macroeconomic/sector features to generate a prediction signal.
The system as claimed in claim 2, wherein the output probability of the stacking meta-learner is calibrated using isotonic regression, and wherein a classification decision threshold applied to the calibrated probability is selected by maximizing the Youden's J statistic on a validation dataset.
The system as claimed in claim 2, wherein the sentiment features are generated by a dual natural-language-processing pipeline comprising a transformer-based financial-domain sentiment model and a lexicon-based sentiment scoring model, whose respective outputs are fused into a composite sentiment feature supplied to the stacking meta-learner.
The system as claimed in claim 2, wherein the macroeconomic/sector features comprise at least one of: an implied-volatility index value, a currency exchange-rate value, a commodity benchmark value, and a sector-relative return metric, each computed contemporaneously with the prediction event and supplied as an input feature to the stacking meta-learner.
The system as claimed in claim 1, wherein the on-device expense-tracking module processes financial SMS messages entirely on the local device using a multi-stage regular-expression pipeline configured to extract transaction amount, merchant identity, and expense category, and to distinguish genuine transactional messages from non-transactional promotional or informational messages, without transmitting message content to an external server.
The system as claimed in claim 1, wherein the mutual-fund evaluation module ranks funds using a weighted composite score computed from Extended Internal Rate of Return (XIRR), a historical risk/volatility measure, the Sortino ratio, and maximum drawdown, in place of ranking by trailing absolute historical returns.
The system as claimed in claim 7, further comprising a Systematic Investment Plan simulator configured to project future investment corpus value using a geometric-progression model of a user-specified periodic contribution step-up rate.
The system as claimed in claim 1, wherein the credit-score calculation module operates as a deterministic, rule-based, explainable model executed entirely on the user's local device, and is configured to identify the lowest-performing contributing credit factor(s) and automatically generate ranked, actionable recommendations for improving said factor(s).
A computer-implemented method for generating a stock-market trend prediction signal within a unified personal finance application, the method comprising: processing historical price and technical-indicator sequence data using a Temporal Convolutional Network and an attention-augmented Long Short-Term Memory network; classifying market conditions using a global LightGBM classifier that receives a detected market regime as a categorical input feature; estimating market volatility using a GARCH-family model; generating a composite sentiment score from aggregated financial news using a dual pipeline comprising a transformer-based financial-domain sentiment model and a lexicon-based sentiment model; retrieving contemporaneous macroeconomic and sector-relative features; combining the outputs of the preceding steps using a stacking meta-learner to produce a prediction probability; calibrating said prediction probability using isotonic regression; and generating a BUY, SELL, or HOLD signal by applying to the calibrated probability a decision threshold selected by maximizing the Youden's J statistic on validation data.
The method as claimed in claim 10, further comprising evaluating the method using a deterministic, seeded historical data-retrieval and back-testing pipeline such that reported predictive performance metrics are independently reproducible.
A computer-implemented method for privacy-preserving expense tracking, comprising: intercepting a financial SMS notification on a user device; passing said notification through a multi-stage on-device regular-expression pipeline to extract a transaction amount, a merchant identity, and an expense category; determining, on-device, whether said notification corresponds to a genuine transaction or a non-transactional promotional or informational message; and recording extracted transaction data locally without transmitting the content of said notification to a remote server.
A computer-implemented method for risk-adjusted mutual fund ranking, comprising: retrieving Net Asset Value data for a plurality of funds on a scheduled basis; computing, for each fund, a composite score as a weighted function of Extended Internal Rate of Return, a risk/volatility measure, the Sortino ratio, and maximum drawdown; and ranking said plurality of funds according to said composite score.
A computer-implemented method for deterministic, explainable credit-score estimation, comprising: evaluating, entirely on a user device and without network connectivity, a plurality of predefined credit-health factors; computing an estimated credit score as a deterministic function of said factors; identifying the lowest-performing factor(s) among said plurality; and generating and outputting ranked, actionable recommendations associated with the identified lowest-performing factor(s).
The system as claimed in claim 1, wherein data derived on-device by the expense-tracking module and the credit-score calculation module is synchronized to the microservices backend in summarized, non-sensitive form only, such that raw transaction message content and raw credit-factor inputs are not transmitted off the user's device.
10. ABSTRACT
A unified, artificial-intelligence-powered personal finance management system and method (“FinSight”) is disclosed, integrating four modules within a single cross-platform application backed by a microservices architecture. A stock-trend prediction module combines a Temporal Convolutional Network and an attention-augmented LSTM with a regime-aware global LightGBM classifier, a GARCH volatility model, dual-pipeline NLP sentiment analysis, and macroeconomic/sector features, fused via a stacking meta-learner whose output is isotonic-calibrated and thresholded using a Youden's-J-optimized cut-off to generate BUY/SELL/HOLD signals. A privacy-preserving expense tracker parses financial SMS notifications entirely on-device via a multi-stage regular-expression pipeline. A mutual-fund module ranks funds using a weighted composite of XIRR, risk, Sortino ratio, and maximum drawdown, and simulates step-up SIP growth. A deterministic, explainable credit-score module evaluates standard factors on-device and issues actionable improvement recommendations. The invention improves prediction robustness and reproducibility, preserves user data privacy, and consolidates fragmented personal-finance tools into a single explainable ecosystem.
